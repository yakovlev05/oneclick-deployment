# oneclick-deployment
Деплой приложений в docker контейнерах по API


Пункты идеи:
- все деплои временные
- есть сущность - deployment - все активные деплои в данный момент
- у одной деплоймента может быть несколько контейнеров и в принципе могут быть сети, образы и прочее
- в рамках одного деплоймента мы это все запоминаем, чтобы потом можно было удалить

MVP:
- создать deployment, просмотр информации по активному
- деплой просто контейнера без ничего
